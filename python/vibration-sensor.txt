通信协议
协议：MODBUS协议 
电平：485电平（默认波特率：9600bps）
通讯格式：数据位8，无校验，停止位1
从站默认地址：16进制：0x50
 读寄存器格式
● 数据是按照16进制方式发送的，不是ASCII码。
● 每个寄存器地址，读取寄存器个数，读取数据均采用两个字节表示。寄存器地址高低位用ADDRH，ADDRL表示，读取寄存器个数高低位用LENH，LENL表示，读取数据高低位用DATA1H，DATA1L表示。
● 读取指令结尾两位为标准CRC校验位。可使用CRC校验位计算工具计算，CRC在线计算网址。
指令发送
Modbus地址	功能码	寄存器高8位	寄存器低8位	读取长度高8位	读取长度低8位	校验位高8位	校验位低8位
ID	0x03（读）	ADDRH[15:8]	ADDRL[7:0]	LENH[15:8]	LENL[7:0]	CRCH[15:8]	CRCL[7:0]
数据返回
Modbus地址	功能码	读取长度	数据高8位	数据低8位	数据高8位	数据低8位	数据高8位	数据低8位	校验位高8位	校验位低8位
ID	0x03（读）	LEN[7:0]	DATA1H[15:8]	DATA1L[7:0]	……	……	DATAnH	DATAnL	CRCH[15:8]	CRCL[7:0]
写寄存器格式
● 数据是按照16进制方式发送的，不是ASCII码。
● 每个寄存器地址，写入数据均采用两个字节表示。寄存器地址高低位用ADDRH，ADDRL表示，写入数据高低位用DATAH，DATAL表示。
指令发送
Modbus地址	功能码	寄存器高8位	寄存器低8位	数据高8位	数据低8位	校验位高8位	校验位低8位
ID	0x06（写）	ADDRH[15:8]	ADDRL[7:0]	DATAH[15:8]	DATAL[7:0]	CRCH[15:8]	CRCL[7:0]
数据返回
Modbus地址	功能码	寄存器高8位	寄存器低8位	数据高8位	数据低8位	校验位高8位	校验位低8位
ID	0x06（写）	ADDRH[15:8]	ADDRL[7:0]	DATAH[15:8]	DATAL[7:0]	CRCH[15:8]	CRCL[7:0]
注：
进行指令写入操作时候需要分三个步骤执行。
第一步解锁0x50 0x06 0x00 0x69 0xB5 0x88 0x22 0xA1，解锁十秒内有效果。
第二步发送需要修改的指令，
第三步保存指令0x50 0X06 0X00 0X00 0X00 0X84 0X4B。

寄存器说明
以下所有示例均为Modbus地址为0x50（默认）情况下的指令，如更改Modbus地址需要相应更改指令中地址与CRC校验位。
SAVE（保存/重启/恢复出厂）
寄存器名称: SAVE
寄存器地址: 0 (0x00)
读写方向: R/W
默认值: 0x0000
Bit	NAME	FUNCTION
15:0	SAVE[15:0]	保存: 0x0000
重启: 0x00FF
恢复出厂: 0x0001
示例：
发送：50 06 00 69 B5 88 22 A1（解锁10S内有用）
返回：50 06 00 69 B5 88 22 A1
发送：50 06 00 00 00 FF C4 0B（重启）
返回：50 06 00 00 00 FF C4 0B
BAUD（串口波特率）
寄存器名称: BAUD
寄存器地址: 4 (0x04)
读写方向: R/W
默认值: 0x0002		
Bit	NAME	FUNCTION
15:4		
3:0	BAUD[3:0]	设置串口波特率： 
0001(0x01) 4800bps 0010(0x02): 9600bps 0011(0x03): 19200bps 0100(0x04): 38400bps 0101(0x05): 57600bps 0110(0x06): 115200bps 0111(0x07): 230400bps
示例：
发送：50 06 00 69 B5 88 22 A1（解锁10S内有用）

发送：50 06 00 00 00 00 84 4B（115200baud下保存）
返回：50 06 00 00 00 00 84 4B

常见问题说明
正常模式下回传频率太低
原因：波特率设置太低
正常模式下记录数据帧数太少
原因：正常模式下，是使用一问一答的modbus通信协议，设置的波特率越高，读取数据频率越高
高速模式下无法退出
原因：传感器未断电。将传感器断电，然后重新上电，传感器会自动恢复正常模式，此时可使用上位机搜索设备，或者自己添加设备。
重上电后无数据
原因1：上位机波特率设置不对，可点击搜索设备
原因2：串口丢失，可检查串口是否存在，如果搜索不到设备，可以重新插拔三合一或六合一，刷新一下电脑，找到识别到的COM口重新连接即可。
上位机搜索不到设备
原因：传感器的地址或波特率可能被修改，耐心等待，需要几分钟的搜索过程。
加速度幅值和频谱为什么没有了
只有在频域算法下才会有这两个数据，时域算法是没有的
